# obsidian-morning-mail

Dropbox에 저장한 옵시디언 할 일을 매일 아침 Gmail로 받아보세요.

**Obsidian → Dropbox → Google Apps Script → Gmail**

## 기능

- 매일 한국 시간 07:00 이후 하루 한 번 발송 (주말 포함)
- 기한 초과, 오늘 마감, 중요 표시를 기준으로 우선순위 정리
- 업무·개인 체크박스 구분 및 완료 항목 제외
- 상위 3개, 추가 마감 항목, 이어서 할 일 최대 5개 요약
- Dropbox OAuth 갱신 토큰 사용: 컴퓨터가 꺼져 있어도 클라우드에서 실행
- 읽기 실패 안내 및 중복 발송 시도 방지
- AI 및 외부 JavaScript 라이브러리 사용 없음

## 시작하기

[설정 안내](설정안내.md)를 따라 Dropbox 앱과 Google Apps Script를 설정하세요.

1. [노트 템플릿](오늘의%20할%20일.md)을 Dropbox의 옵시디언 보관함에 복사합니다.
2. `Code.gs`와 `appsscript.json`을 Google Apps Script 프로젝트에 넣습니다.
3. 스크립트 속성에 수신 주소, 노트 경로, Dropbox 인증 정보를 설정합니다.
4. `previewDigest`로 내용을 확인한 뒤 `installSchedule`로 예약합니다.

코드 업로드만으로 계정 연결이나 메일 발송이 시작되지는 않습니다. 인증 정보는 저장소에 커밋하지 않고 Apps Script 속성에 보관하세요.

## 작성 예

```markdown
## 업무
- [ ] 견적서 보내기 📅 2026-09-10 ⭐
- [ ] 회의 자료 검토하기

## 개인
- [ ] 도서관 책 반납하기 📅 2026-09-12
- [x] 인터넷 요금 납부하기
```

## 테스트

Node.js 18 이상에서 외부 연결 없이 실행합니다.

```sh
node test.cjs
```

12개 모의 테스트로 파싱, 우선순위, 인증 갱신 요청, 한글 경로, 실패 처리, 중복 방지 등을 확인합니다. 실제 OAuth 연결과 Gmail 예약 수신은 계정 설정 후 별도로 확인해야 합니다.

## 운영 참고

목표 수신 시간은 07:00~07:05이며 Google 실행 지연으로 늦어질 수 있습니다. 컴퓨터에서 Dropbox로 아직 동기화되지 않은 내용은 반영되지 않습니다. 발송 결과가 불확실한 경우 중복 방지를 위해 당일 자동 재시도하지 않습니다. 자세한 동작과 복구 방법은 [설정 안내](설정안내.md)에 있습니다.
